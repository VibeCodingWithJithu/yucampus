# Design system (match design-reference/screens)

Brand: YuCampus wordmark = "Yu" teal + "Campus" ink, Plus Jakarta Sans ExtraBold. Logo files in design-reference/logo.
Parent brand "by Yubhian Technologies" shown under the wordmark where space allows.

Colours
- Primary indigo #2B3990 (hover #1E2870), primary soft #E8EAF6
- Teal (on track/approved) #0E7068, soft #DDF1EE, light teal on dark #5ED1C4
- Amber (in review/needs attention) text #A15C07 / #7A4505, fill #C77A12, soft #FDF0DC
- Red (missing/rejected) #B3261E / #8F1D17, soft #FBE4E2
- Ink #121733, muted text #545B73, body secondary #3B4157
- Background #F5F6FA, surface #FFFFFF, border #E3E6EF, subtle row border #EEF0F4
- Manual markers orange #C2410C (documentation only)
Every status uses colour AND a text label.

Typography: Plus Jakarta Sans (Noto Sans for Telugu/Hindi). H1 28/700, H2 17/700, body 14, small 12-13.
Spacing: 8px grid; cards padding 20-24; gaps 12-24. Radius: cards 12, inputs/buttons 8, pills 999.
Controls: height 44 (touch target), inputs with visible labels. Sidebar 240px; main content padding 32.
Layout: left sidebar nav (13 items) + top header (breadcrumb, H1, actions). Faculty mobile: bottom nav with central upload button.
Icons: Lucide-style 1.75 stroke.
